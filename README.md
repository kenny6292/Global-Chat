# Global Chat

Premium global social communication platform.

## Product direction
- Premium responsive web application
- Production Supabase backend
- Real authentication, profiles, messaging and communities
- Global discovery and country explorer
- PWA and Capacitor-ready for Android/iOS

## Development
`npm install`
`npm run dev`

## Environment
Copy `.env.example` to `.env.local` and provide:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

The app intentionally does not include or expose a Supabase secret/service-role key in the browser.
